Magento Connector

Odoo-led Magento catalog publishing and queued sales order imports. Odoo maintains your catalog, prices and physical stock; Magento supplies online orders, customer registrations and financial documents.

Odoo 19 Magento REST API (V1) OAuth 1.0a / Bearer token Requires queue_job

What Synchronizes, and Which Way

Each system stays the owner of its own data. No custom Magento extension is needed.

ODOO → MAGENTO
Catalog & stock
Categories, attributes, products, prices, images and warehouse source quantities.
MAGENTO → ODOO
Orders & customers
New orders from selected store views and new customer registrations.
ODOO → MAGENTO
Fulfillment
Completed deliveries and tracking. Unprocessed whole-order cancellations sync both ways.
MAGENTO → ODOO
Accounting
Invoices and credit memos imported as drafts; reported payment amounts are read.

Key Features

Everything runs as background jobs on a dedicated magento queue channel.

🧭

Guided Setup

A five-step wizard: Connection, Magento scope, Mappings, Automation and Review. It discovers store views, attribute sets, root categories and inventory sources from your store. New connections stay paused until you enable them.

📦

Catalog Publishing

Publish selected product categories (with hierarchy), variant attributes and options, simple and virtual products, and configurable products with their variants. Includes product images and custom catalog field mappings. Existing Magento records can be linked instead of recreated.

💲

Prices & Change Detection

Prices come from the connection pricelist. Price-only changes can be sent as batch updates. The connector compares what it would send with the last acknowledged export, so unchanged records do not trigger duplicate writes.

🏬

Inventory (MSI Sources)

Map each Odoo warehouse to an exact Magento MSI source code and test it. Physical on-hand stock is exported for inventory-enabled products, in batches. Magento reservations are left untouched.

🛒

Queued Order Import

Polls new orders from the selected store views into an Order Inbox and creates Odoo sales orders. It uses explicit tax-rate mappings and a shipping service product, and checks that Magento and Odoo totals match before saving. Automatic confirmation is optional, and failed orders can be retried.

👥

Customers & Addresses

Import new Magento customer registrations, and export customer and address changes made in Odoo. Each has its own switch and shares one interval.

🚚

Shipments, Tracking & Cancellations

Export completed Odoo deliveries as Magento shipments from the mapped source, with carrier and tracking numbers. Unprocessed whole-order cancellations sync in either direction.

🧾

Invoices, Credit Memos & Returns

Import Magento invoices and credit memos as draft Odoo documents in a chosen sales journal, and read reported payment status. You can prepare a return delivery from an imported credit memo.

👁

Publish / Unpublish Control

Unpublish or republish product listings from Odoo. New listings are created disabled unless "Publish new products as enabled" is set.

📊

Operations Dashboard

Shows successful syncs today, failed and waiting jobs, and pending orders. It has a Test Worker probe and read-only diagnostics for credentials, scheduler, store scope and API read access.

📝

Sync Logs

Every synchronization is logged with field-level change details. Old logs are cleaned up automatically after a set number of days (90 by default; 0 keeps them indefinitely).

🔒

Safe & Multi-Company

Viewer and Administrator access groups, with credential fields restricted to administrators. Records follow company rules. Temporary Magento errors (HTTP 429/5xx) are retried by the job queue. Synchronization is blocked on neutralized databases.

How It Works

1
Connect
Create a Magento integration and enter its credentials (OAuth 1.0a or Bearer token) and the HTTPS store URL in Guided Setup.
2
Discover & map
Discover store views, attribute set and root category. Map warehouses to MSI sources and Magento tax rates to Odoo taxes.
3
Choose automation
Turn on the flows you need (orders, catalog, inventory, customers, fulfillment, financials) and set their intervals.
4
Verify & enable
Run Test Worker and Diagnostics, resolve any errors, then enable synchronization.
5
Run
A scheduled action checks due work every minute and queues jobs. Monitor everything from Operations and Sync Logs.

Dependencies

REQUIRED MODULE

Job Queue (queue_job)

All synchronization (order polling, catalog, stock, customer, fulfillment and financial jobs) runs through queue_job.

Get queue_job on Odoo Apps →
ALSO REQUIRED
  • Odoo modules: Sales (sale_management) and Sales & Stock (sale_stock)
  • Python packages: requests, requests_oauthlib
  • Magento: an HTTPS store with an integration that grants API access to the resources your enabled flows use
!
Install and configure queue_job first

queue_job must be installed and its job runner configured on the server before you install Magento Connector. Load it as a server-wide module in your odoo.conf, then restart Odoo: 

[options]
server_wide_modules = base,web,queue_job

Keep any other server-wide modules your deployment already uses, and make sure the Magento: Schedule Synchronization scheduled action stays active.
